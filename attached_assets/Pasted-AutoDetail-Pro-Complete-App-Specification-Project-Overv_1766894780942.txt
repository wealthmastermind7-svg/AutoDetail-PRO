AutoDetail Pro - Complete App Specification
Project Overview
Build a production-ready, scalable multi-tenant booking platform for auto detailing businesses using React Native (Expo) with iOS and Android support. The app features a freemium monetization model powered by RevenueCat, offering business owners a comprehensive dashboard to manage appointments, services, and customers, while providing customers with a seamless public booking experience.

{

Authentication & Security
Token-Based Ownership
Each business has a unique ownerToken (UUID)
Admin routes require x-owner-token header
Middleware validates token against business ownership
Public routes (booking, services list) remain open
Protected Routes Middleware
async function verifyBusinessOwnership(req, res, next) {
  const token = req.headers['x-owner-token'];
  const business = await storage.getBusinessByToken(token);
  if (!business || business.id !== req.params.businessId) {
    return res.status(403).json({ error: 'Unauthorized' });
  }
  req.business = business;
  next();
}

Key Implementation Notes
Multi-tenancy: All data queries filter by businessId
Haptic feedback: Use on all interactive elements (Light, Medium, Heavy)
Safe areas: Always respect device notch/home indicator
Error handling: Graceful fallbacks, retry logic, user-friendly messages
Offline support: Cache critical data with AsyncStorage
Performance: Use FlatList for lists, memoize expensive renders
Accessibility: 44x44px touch targets, proper labels, contrast ratios
